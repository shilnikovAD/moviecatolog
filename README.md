# MovieCatalog

Веб-приложение для просмотра каталога фильмов с возможностью совместного просмотра (Watch Party).

## Функционал

- Просмотр популярных фильмов
- Поиск фильмов
- Детальная информация о фильмах
- Добавление фильмов в избранное
- Совместный просмотр фильмов с синхронизацией между вкладками
- Чат в режиме Watch Party

## Технологии

- **Frontend**: React 19, TypeScript, Vite
- **State Management**: Redux Toolkit
- **API**: The Movie Database (TMDB)
- **Стилизация**: CSS Modules
- **Тестирование**: Vitest, Cypress
- **Документация**: Storybook

## Требования

- Node.js 18+ (рекомендуется LTS версия)
- npm или yarn

## Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd moviedata
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка API ключа TMDB

1. Зарегистрируйтесь на [TMDB](https://www.themoviedb.org/) (если еще не зарегистрированы)
2. Получите API ключ в разделе [API](https://www.themoviedb.org/settings/api)
3. Откройте файл `src/services/movieApi.ts`
4. Замените значение `API_KEY` на ваш реальный API ключ:

```typescript
const API_KEY = 'ваш_api_ключ_здесь';
```

### 4. Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### 5. Сборка для продакшена

```bash
npm run build
npm run preview
```

## Использование

### Просмотр фильмов

- На главной странице отображаются популярные фильмы
- Используйте поисковую строку для поиска фильмов
- Кликните на карточку фильма для просмотра деталей

### Избранное

- Нажмите сердечко на карточке фильма, чтобы добавить в избранное
- Перейдите во вкладку "Favorites" для просмотра сохраненных фильмов

### Совместный просмотр

1. Перейдите на страницу фильма
2. Нажмите "Watch" для просмотра трейлера
3. Для Watch Party:
   - Перейдите по ссылке `/watch-party/{movieId}`
   - Введите имя и создайте комнату или присоединитесь к существующей
   - Скопируйте ссылку и откройте в новой вкладке для синхронизации
