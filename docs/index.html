Описание идеи

  • [translate:Проблема:] сложно находить персонализированные подборки фильмов и сохранять любимые в одном месте.
  • [translate:Решение:] удобный каталог фильмов с поиском, деталями и списком избранного (локальное хранение).
  • [translate:Ключевой функционал:] просмотр популярных, поиск, страница фильма, избранное, адаптивный UI.
  • [translate:Преимущество:] лёгкая кастомизация рекомендаций, минималистичный UI, офлайн-доступ к избранному.

Пользовательские сценарии

  1. [translate:Пользователь открывает главную] — видит популярные фильмы — использует поиск по заголовку — открывает страницу фильма.
  2. [translate:Пользователь на странице фильма] — добавляет в избранное — проверяет список избранного в профиле/странице "Избранное".
  3. [translate:Пользователь фильтрует результаты] по жанру/году — кликает фильм — делится ссылкой на фильм.

API (REST)

Интеграция через TMDB + собственные endpoint'ы при необходимости.

  • GET /movie/popular?page={n} — список популярных
  • GET /search/movie?query={q}&page={n} — поиск
  • GET /movie/{id} — детали фильма
  • Клиент хранит токен TMDB в окружении; любимые хранятся в localStorage (опционально синхронизация с бэком).

Пример ответа (сокращённо):

{
  "id": 123,
  "title": "Название",
  "overview": "Описание...",
  "poster_path": "/path.jpg",
  "release_date": "2024-01-01"
}
